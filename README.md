# 1% Daily for Android

One money goal. Every day, 1% closer. Track your goal, plan your Top 3 each day, commit to 3 results a week, and see which of your side startups are actually paying off.

## Download

**[Download 1% Daily (APK)](https://github.com/1-percent-daily/public-app-release/releases/latest/download/one-percent-daily.apk)**: works on every Android phone running Android 7 or newer.

Smaller downloads, if you know which one fits your phone:

- [64-bit phones (arm64)](https://github.com/1-percent-daily/public-app-release/releases/latest/download/one-percent-daily-arm64.apk): most recent phones
- [32-bit phones (armv7)](https://github.com/1-percent-daily/public-app-release/releases/latest/download/one-percent-daily-armv7.apk): older and entry-level phones

If unsure, take the first link.

## Install

1. Open the downloaded file.
2. If Android asks, allow installs from your browser ("Unknown sources").
3. Tap **Install**.

To update, download and install the new version over the old one. Your data stays on your phone and is kept.
